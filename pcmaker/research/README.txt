PCmaker: происхождение данных

verification-core.json и verification-support.json — ручная сверка основных
характеристик с производителями 28.10.2026: 33 модели. values содержит только
подтверждённые поля; assumptions и limitations сохраняют пределы проверки.
Остальные реальные товары доступны вручную, но не входят в автосборку.
Это не проверка всех сочетаний BIOS, QVL, тепловой модели и монтажных зазоров.
У RTX 4060 VENTUS 2X BLACK 8G статус pending: MSI указывает 115 либо 120 Вт
без однозначной привязки ревизии. Не присваивать проверку автоматически.

offers-by-2026-10-28.json — 19 предложений с ценой, датой, карточкой и кратким
подтверждением. Это разовая проверка, не непрерывный парсинг. Наличие под заказ
и необходимость уточнения обозначены unknown; условия оплаты сохранены в note.
Исследование не гарантирует минимальную рыночную цену.

Возраст предложения: до 7 UTC-календарных дней включительно — fresh,
начиная с восьмого — stale. Прошедшая дата не обновляется при импорте.
Строгая автосборка исключает устаревшие предложения. При разрешении оценок
старые предложения сохраняют источник и получают резерв 10%; авторские
оценки доступны только для RUB. BYN никогда не получается пересчётом RUB.
Известное отсутствие в продаже исключает предложение из автосборки.
Историческая сумма в ручном конструкторе остаётся справочной с предупреждением.

Обновление данных (из папки pcmaker):
1. Прочитать первоисточники; исправить canonical dist/catalog*.js.
2. Обновить evidence JSON с датой, значениями и ограничениями.
3. node scripts/build-verification.mjs
4. Для цен: node scripts/update-prices.mjs путь-к-проверенному-снимку.json
   Импорт сливает пакет с прежним снимком. Поддерживаются Москва/RUB и Минск/BYN.
   Новые магазины BY сначала добавить в явный список dist/regions.js.
5. node firebase/generate-rules.mjs
6. npm run build:firebase
7. npm run build

Проверка сборки сверяет evidence с полями каталога и сгенерированным manifest,
хеши исходников Firebase bundle, цены обоих регионов и запускает unit-тесты.
Изменение подтверждённого значения без обновления evidence снимает статус
проверки в приложении и блокирует выпуск. Наличие ссылки не равно проверке.

Если изменились доверенные факты совместимости, после локальных проверок
синхронизировать catalog-facts.json в согласованный проект Firebase согласно
firebase/SETUP.txt. Изменения правил доступа требуют отдельных emulator-тестов.
В этом выпуске правила доступа не менялись.
