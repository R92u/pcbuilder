ОБНОВЛЕНИЕ ПУБЛИЧНЫХ ПРЕДЛОЖЕНИЙ — 08.11.2026

Результат
dist/live-prices.json — дополнительный слой подтверждённых цен и отдельный
журнал попыток проверки. Исходные prices.json, prices-by.json и цены каталога
не переписываются. Валюты RUB, BYN, USD хранятся отдельно без конвертации.

Формат
schemaVersion: 1
checkedAt: ISO timestamp последней попытки, не дата подтверждения всех цен.
items.ru / items.by / items.usd: product ID -> предложение в формате каталога.
checks.ru / checks.by / checks.usd: product ID -> attemptedAt, status, reason, url.
offer.date: московская календарная дата успешной проверки конкретного товара.
Если проверка заблокирована, завершилась ошибкой или не нашла однозначное
предложение, прежние offer.price и offer.date остаются прежними.

Запуск из корня репозитория
node pcmaker/scripts/refresh-prices.mjs
node pcmaker/scripts/refresh-prices.mjs --host=kns.ru
node pcmaker/scripts/refresh-prices.mjs --region=by --limit=20
node pcmaker/scripts/import-reviewed-offers.mjs pcmaker/research/offers-pc-2026-11-08.json
node pcmaker/scripts/check.mjs

Targets берутся из опубликованных снимков цен ПК, иностранных предложений,
каталога периферии и уже добавленных items live-prices.json. Поэтому вручную
проверенный новый прямой URL автоматически становится целью будущих запусков.
Поиск новых товаров и исправление перенесённых/ошибочных карточек остаются
ручной работой: скрипт не подменяет выбранную модель похожей или более дешёвой.

Источники и ограничения
Поддерживается первичная schema.org Product/Offer разметка Regard, 5element,
ANDPRO, Redragon, ряда белорусских магазинов, а также однозначные h1/microdata
KNS и Masterdom. Logitech и Newegg проверяются только при наличии точного
Product/Offer. Lifebook-Shop: цена для физических лиц из основного блока
должна совпасть с product:price:amount; отдельная цена для юрлиц не используется.
Диапазоны AggregateOffer/lowPrice не подходят. DNS и остальные
источники без проверенного парсера явно отмечаются unsupported-source.
Рекомендации isSimilarTo, карусели товаров, кредитные платежи, купоны, цены
бывших в употреблении товаров и предложения без подтверждённой валюты
не используются. Требуется точный SKU/MPN либо полный набор модельных слов.
Обозначение InStock берётся из разметки магазина; это не резерв товара и не
гарантия возможности доставки по адресу пользователя. OutOfStock, SoldOut и
Discontinued явно отмечаются как отсутствие. Рекомендованная цена
производителя остаётся kind=manufacturer, наличие у продавца не утверждается.

Безопасность и нагрузка
Разрешены HTTPS и явный список публичных доменов. Редирект разрешён только
в пределах того же магазина. Нет браузерных сессий, cookie, секретов, обхода
CAPTCHA или антибот-защиты. Проверяется robots.txt; при невозможности его
прочитать сайт пропускается (404 означает отсутствие правил). Три домена
обрабатываются параллельно, запросы внутри домена последовательны с паузой
не менее 1,1 с. Таймаут 20 с, максимум 4 МБ на страницу и 500 предложений.
При HTTP 429 или отказе в доступе остальные запросы к этому магазину в текущем
запуске прекращаются; три последовательных сетевых сбоя также останавливают его.
Ответ 304 не считается новой проверкой без тела подтверждающей страницы.
В публичный отчёт попадают только количество проверок и безопасные коды причин.

Публикация
GitHub Actions «Refresh public price offers» запускается ежедневно в 04:23 UTC
(07:23 Москва/Минск), также доступен ручной workflow_dispatch. Расписание
GitHub может задерживаться; это ежедневная проверка, не цены в реальном времени.
После проверок бот коммитит только live-prices.json и price-refresh-last-run.json
в main. Обычный auto-deploy Render получает этот commit. GitHub Pages запускается
через workflow_run после успешного refresh, потому что push от GITHUB_TOKEN
сам по себе не запускает push-workflow. Pages берёт актуальную main и повторно
валидирует файлы перед публикацией. Конфликт при rebase останавливает выпуск;
force push не используется.
