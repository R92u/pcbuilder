PCmaker / Firebase

Production project: pcmaker-school-r92u. Frontend: https://pcmaker-olnw.onrender.com/
Google sign-in and Firestore are enabled. Billing is not enabled (Spark).
The community market is /market.html; the builder is /. Both share the logo
navigation menu. Draft parts, fans, lighting and region persist between pages.
Market filtering and pagination run in Firestore, including region and author.
Title search uses a case-insensitive prefix and alphabetical order.
The browser configuration in dist/firebase-config.json is public SDK configuration,
not a service-account credential. Never commit CLI tokens or private keys.

App Check (reCAPTCHA Enterprise):
  Both Firebase App Check API and reCAPTCHA Enterprise API must be enabled
  in the project. A provider configuration alone does not enable the exchange
  API for the public SDK key.
  The public appCheckSiteKey is restricted to pcmaker-olnw.onrender.com.
  The browser initializes App Check before Auth/Firestore, obtains an attestation
  token, and refreshes it automatically. Token TTL is 1 hour; risk threshold 0.5.
  Keep the standard reCAPTCHA badge visible. Do not hide it in application CSS.
  App Check complements Firestore Rules; it does not replace Google sign-in,
  ownership checks, quotas, or validation. It cannot prevent all abuse.
  Localhost uses only demo emulators: never register localhost on the production
  reCAPTCHA key or put App Check debug tokens in source, builds, or public logs.
  On a new domain, update reCAPTCHA domains, Auth authorized domains and the
  browser API key's HTTP referrers before publishing there.
  Deploy the App Check client and verify the public Market and Google sign-in
  before enabling enforcement in Firebase Console > Security > App Check.
  Review verified/unverified traffic first; existing tabs need a page reload.
  This project targets Firestore enforcement. Authentication enforcement is
  separate and requires Firebase Authentication with Identity Platform; it has
  not been enabled or upgraded as part of this Spark configuration.
  Verified 2026-10-28: Firestore enforcement is ENFORCED. An anonymous direct
  REST query that succeeded before now returns 403 without App Check, including
  with a forged production Referer. The deployed Market still loads and Google
  sign-in succeeds. Other Firebase products do not inherit this enforcement.
  If legitimate traffic is blocked, inspect App Check metrics and domain/API
  restrictions. Keep Firestore Rules intact; never fix it by opening database
  access or committing a production debug credential.

Public API key restrictions:
  HTTP referrers: the production Render domain and the project's firebaseapp.com
  and web.app domains, HTTPS only. This is an additional browser restriction,
  not proof of authorization: non-browser callers can forge a Referer header.
  APIs: Firebase Management, Logging, App Check, Identity Toolkit, Secure Token,
  Firestore, Datastore and Firebase Rules. Unused products (including AI APIs)
  are not permitted. Check the official Firebase API-key allowlist requirements
  when adding another Firebase product.

Repository protection:
  Keep the repository public. main forbids deletion and non-fast-forward pushes;
  ordinary direct pushes remain allowed. Secret scanning, push protection,
  Dependabot alerts and automated security updates are enabled.
  .gitignore excludes local environment files and administrator credentials.
  It cannot remove an already committed secret. If a real secret leaks, revoke
  or rotate it first, then remove it from history. Firebase browser configuration
  is intentionally public; service-account private keys and CLI tokens are not.
  Use account two-factor authentication; account-level 2FA was not verified by
  the repository API audit.

Dependency audit, 2026-10-28:
  Compatible security updates reduced pnpm audit from 27 advisories to 3.
  pnpm audit --prod reports zero. The remaining firebase-tools development
  dependencies are basic-ftp 5.x (high; fixed in 6.2.1), uuid 9.x (moderate;
  fixed in 11.1.1), and @opentelemetry/core 1.x (moderate; fixed in 2.8.0).
  They are absent from the static browser bundle. Do not force cross-major
  overrides without testing the CLI workflows that consume these packages.
  Recheck upstream firebase-tools and the audit before updating developer tools.

Local development (Node 24, pnpm, Java 21 for emulators):
  pnpm install --frozen-lockfile
  pnpm start
  pnpm exec firebase emulators:start --only auth,firestore --project demo-pcmaker
  node firebase/publish-catalog.mjs demo-pcmaker
The localhost frontend uses emulators only; it never writes to production.

Checks:
  pnpm test
  pnpm run test:rules
  pnpm run build

After changing catalog facts or Firebase client:
  node firebase/generate-rules.mjs
  pnpm run build:firebase
  pnpm run test:rules
  node firebase/publish-catalog.mjs pcmaker-school-r92u
  pnpm exec firebase deploy --only firestore:rules,firestore:indexes --project pcmaker-school-r92u
Commit the generated browser bundle, rules and catalog facts. Render's static
build checks the committed files and does not need Firebase admin credentials.

Collections:
  builds: public visible publications; only the author may edit/delete theirs.
  publishLimits: atomic publication quota (50 per account, 10-second interval).
  reports: one report per publication/account, visible only to moderators.
  catalog: trusted compatibility facts; client writes and reads are denied.
Project owners can moderate in the Firebase console. The optional in-app
moderation screen requires the Firebase Auth custom claim admin=true, assigned
through a trusted administrator tool to the intended user's UID.

Prices are dated snapshots, not live offers. Belarus has independent BYN prices
from 5element.by. Missing prices stay missing; Russia prices are never converted.
Belarus budget auto-build requires prices in every category and currently cannot
complete a build because CPU quotes from 5element are unavailable.
AIO geometry and thermal coefficients are educational approximations. Retail
radiator support is checked against case manuals; validate exact RAM/VRM clearance
and mounting hardware before purchase.
