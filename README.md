# PCmaker

Школьный 3D-конструктор компьютера и рабочего места. В конструкторе можно подобрать комплектующие, проверить совместимость и запустить учебную симуляцию нагрева. На странице рабочего места можно сравнить периферию, а в маркете — посмотреть сборки сообщества.

В дорожную карту входят расширение бюджетного ассортимента, обновление цен и улучшение подключения устройств.

Исходники приложения, каталога и проверок находятся в [pcmaker](pcmaker/).
